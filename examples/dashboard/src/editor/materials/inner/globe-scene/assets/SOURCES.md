# GlobeScene fixed visual assets

- `earth-blue-marble.jpg` — NASA Scientific Visualization Studio, “Flat Earth”, Blue Marble imagery: https://svs.gsfc.nasa.gov/3615/
- `2mass-galactic-plane.jpg` — NASA Scientific Visualization Studio, 2MASS all-sky Milky Way imagery: https://svs.gsfc.nasa.gov/30020/
